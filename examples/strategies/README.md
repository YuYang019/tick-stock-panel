# 示例策略

9 个日线 `matrix_native` 策略模板。

**使用：** 复制到 `data/strategies/custom/` 后，在策略页点「重载」（或调用 `POST /api/strategies/reload`），即出现在策略池；参数可在策略设置中调整。

| 文件 | 策略 | 核心条件 | 情绪择时 |
|---|---|---|---|
| `custom_ma_bull_divergence.py` | 均线多头发散 | MA5>10>20>60，MA5-MA20 间距扩大，MA20 上行 | — |
| `custom_volume_breakout.py` | 放量突破 | 收盘创 60 日新高，量比≥2，涨幅 3%~9.5%，收在高位 | — |
| `custom_golden_cross.py` | 金叉共振 | MA5 上穿 MA20 + 近 3 日 MACD 金叉，收盘在 MA60 上 | — |
| `custom_ma_convergence.py` | 均线粘合突破 | 四线粘合 5 日后放量阳线站上四线 | — |
| `custom_rps_strength.py` | RPS 强度 | RPS120≥90，行业内 RPS60≥80，站上 MA60/MA120 | — |
| `custom_rps_pullback.py` | 强势回踩 | RPS120≥80 但 RPS20≤50，回踩 MA20 收阳 | — |
| `custom_rps_rising.py` | RPS 新锐 | RPS20 近 5 日从 ≤60 跃升到 ≥85，RPS60≤85，行业 RPS20≥70 | 启动/主升/高潮 |
| `custom_volume_shrink_pullback.py` | 放量缩量回踩 | 前置：近 10 日 RPS20 峰值≥80，20 日跑赢中证全指且 RS 线上行；触发：放量后缩量回调 5%~15%，KDJ J≤-10，守 MA60 | 非退潮/冰点 |
| `custom_accumulation.py` | 主力建仓 | 20 日对数价线性抬升（R²≥0.75），上涨日≥55%，上涨日均量/下跌日均量≥1.2，无大阴线，波动低，未过热 | — |

## 情绪择时

策略文件可声明：

```python
REGIME_PHASES = ["ignite", "rally", "climax"]
```

阶段 id 取自 `market_phase`：`ice` 冰点 / `ignite` 启动 / `rally` 主升 / `climax` 高潮 / `ebb` 退潮 / `repair` 修复。

- **选股：** 按前一交易日的阶段拦截开仓，结果字段 `regime_blocked` 给出原因；卖出信号不受影响。
- **回测：** 未传 `regime_filter` 时默认使用该声明；传 `{}` 则关闭择时，用于对照。

## 回测参考

10 只持仓，次日开盘成交，含手续费与滑点。样本内为 2023-12 ~ 2025-06，样本外为 2025-07 ~ 2026-09，样本外参数未调整。

| 策略 | 样本内 | 样本外 |
|---|---|---|
| RPS 新锐（含择时） | -28% / 回撤 -32% | -9% / 回撤 -19% |
| 放量缩量回踩 | -8% / 回撤 -16% | +8% / 回撤 -15% |
| 主力建仓 | -8% / 回撤 -29% | +15% / 回撤 -21% |

同期上证指数约 +17%（2024-10 ~ 2026-09）。前 6 个模板在两年区间均大幅跑输。

注意：这些是框架模板，均未做参数寻优。行业内 RPS 在行业归属存档开始（2026-10-11）之前使用当前快照，存在未来函数偏差。实盘前请自行回测。
